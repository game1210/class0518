# Anti-Boring Inc. - AI 自動化公司

這是我在「創新服務專題製作」課程中建立的一人公司專案。

## 公司宗旨
用 AI 取代無意義的重複勞動。

## 專案開發筆記 (Reflection)
- **Phase A-B**: 定義了公司的定位為「瑣事清道夫」。
- **Phase C 卡點紀錄**: 在安裝 Gemini CLI 時遇到 Node.js 環境相容性問題，導致無法直接在終端機運行調度邏輯。
- **解決方案**: 為了確保專案進度，我改以「文件導向設計（Document-driven Design）」，將 Agent 的邏輯完整定義在 `agents/` 資料夾中。雖然沒有透過 CLI 運行，但這組 Prompt 可以在任何 LLM 網頁版中手動跑通。
- **心得**: 這次練習讓我學到，AI 公司的護城河不是 CLI 工具，而是你如何精準地拆解「瑣事流程」並定義「Agent 職責」。
